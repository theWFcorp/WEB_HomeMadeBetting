# WEB_HomeMadeBetting 🏓

Веб-приложение **HomeMade Betting** — для домашних дружеских матчей и учёта прогнозов.

> ⚠️ Это **не букмекерская контора**. Сервис не принимает и не хранит денежные
> средства, не производит выплат и не является организатором азартных игр.
> Все суммы и коэффициенты — виртуальные, только для автоматического расчёта
> результатов между друзьями.

## Возможности
- Спортивный постер матча (Сергей vs Максим, Best of 7, до 4 побед)
- Прогнозы: имя + исход с коэффициентом + виртуальная сумма, несколько прогнозов
- Спецставки (любые пользовательские рынки)
- Два режима коэффициентов: **фиксированные** и **динамические** (авто-пересчёт)
- Админ-панель: создание/редактирование матча, открытие/закрытие приёма,
  ввод результата, участники, экспорт JSON/CSV, PIN
- QR-код и ссылка-приглашение, коды прогнозов (полностью без сервера)
- Рейтинг, история матчей, Зал славы, статистика
- Тёмная/светлая тема, адаптив, PWA (офлайн + установка на телефон)

## Стек
Один самодостаточный `index.html` (HTML + CSS + JS, шрифт и QR-генератор
встроены). Бэкенда нет — данные хранятся локально в браузере, обмен через
ссылки и коды. Разворачивается на любом статическом хостинге.

## Файлы
| Файл | Назначение |
|---|---|
| `index.html` | Само приложение (открывается даже двойным кликом) |
| `manifest.webmanifest` | PWA-манифест |
| `sw.js` | Service worker (офлайн-кэш) |
| `icon.svg` | Иконка приложения |
| `assets/` | Исходники (стили, модули JS) — для правок |

## Локальный запуск
Откройте `index.html` в браузере, либо поднимите статический сервер:
```bash
python -m http.server 8000
```

## Публикация на GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)` → Save.
Через ~1 минуту сайт будет доступен по адресу
`https://<user>.github.io/WEB_HomeMadeBetting/`.
